# prais

R package implementing the Prais-Winsten estimator for linear regression models
with AR(1) serially correlated errors. Source lives in `R/`, documentation in
`man/` (generated by roxygen2), tests in `tests/testthat/`, and the vignette in
`vignettes/`.

## Branching workflow

- `main` holds **only the currently released version**. It advances when a
  release is cut, not during development, so that it stays a reliable pointer to
  what is on CRAN and archived on Zenodo.
- `dev` is the integration branch for ongoing development.
- New work goes on a branch created from `dev`, and is merged back into `dev`.
  Pull requests target `dev`, never `main`, unless the change *is* a release.
- Releases are merged from `dev` into `main` and tagged there.

## Common commands

Run the test suite:

```r
devtools::test()
```

Regenerate documentation and `NAMESPACE` after editing roxygen comments:

```r
devtools::document()
```

Full package check, as CRAN runs it:

```r
devtools::check()
```

## Conventions

- Documentation in `man/` and `NAMESPACE` are generated — edit the roxygen
  comments in `R/`, then re-run `devtools::document()` rather than editing the
  generated files by hand.
- `README.md` is knit from `README.Rmd`; edit the `.Rmd`.
- Datasets in `data/` are built by the scripts in `data-raw/`.
- User-visible changes get an entry in `NEWS.md` under the development version.
- Tests use testthat edition 3.
